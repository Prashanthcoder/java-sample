## 🚀 Getting Started

### Prerequisites

- Java JDK 8 or higher
- Any IDE (IntelliJ IDEA, Eclipse, VS Code) or terminal

### Clone the Repository

```bash
git clone https://github.com/Prashanthcoder/java-sample.git
cd java-sample
```

### Compile and Run

```bash
# Compile a specific file
javac FileName.java

# Run the compiled class
java FileName
```
